# PR Review Test

フロントエンドのPRテスト用レポジトリです。PRレビューのワークフローをテストできるシンプルなWebサイトを提供します。

## 🚀 機能

### 📊 ダッシュボード
- レビュー待ちのPR数
- 完了済みレビュー数
- 平均レビュー時間

### 📋 PR一覧
- PRの一覧表示
- ステータス別フィルタリング（レビュー待ち、承認済み、却下）
- 優先度別フィルタリング（低、中、高、緊急）
- タイプ別フィルタリング（新機能、バグ修正、改善、リファクタリング、ドキュメント）
- タイトル・説明・作成者での検索機能
- 各PRの詳細表示とレビュー開始
- **新機能**: 高度な検索（日付範囲、レビュアー、ラベル）

### ✍️ レビューフォーム
- PR番号の自動入力
- レビュアー名の入力
- レビューコメントの記入
- レビュー結果の選択（承認、却下、修正が必要）
- 5段階評価システム（星評価）

### 🆕 PR作成
- PRタイトルと説明の入力
- 作成者名とブランチ名の設定
- PRタイプと優先度の選択
- ファイルアップロード機能
- ラベルとレビュアーの選択
- 下書き保存機能

### 📈 **新機能**: 分析・統計
- 月別PR作成数のグラフ表示
- レビュー時間分布の可視化
- 詳細統計情報（平均レビュー時間、完了率、最長・最短時間）

### ⚙️ **新機能**: 設定管理
- 通知設定（メール、ブラウザ通知、通知間隔）
- 表示設定（1ページあたりの表示件数、自動更新間隔）
- データ管理（エクスポート・インポート、データクリア）

### 🔔 **新機能**: 通知システム
- 通知センター
- ブラウザ通知
- 定期的な通知チェック
- 通知履歴の管理

## 🛠️ 技術スタック

- **HTML5** - セマンティックなマークアップ
- **CSS3** - モダンなスタイリングとレスポンシブデザイン
- **Vanilla JavaScript** - フレームワークに依存しない実装
- **Material Design** - 美しいUI/UX

## 🚀 使用方法

### 1. ローカルでの実行
```bash
# リポジトリをクローン
git clone https://github.com/holonincjp/reviewtest.git
cd reviewtest

# ブラウザでindex.htmlを開く
open index.html
# または
# ローカルサーバーを起動（推奨）
python -m http.server 8000
# または
npx serve .
```

### 2. ブラウザでの操作
- **ダッシュボード**: サイトの概要と統計情報を表示
- **PR一覧**: サンプルPRデータの一覧表示とフィルタリング
- **レビューフォーム**: PRレビューの入力と送信

### 3. キーボードショートカット
- `Ctrl/Cmd + 1`: ダッシュボードに移動
- `Ctrl/Cmd + 2`: PR一覧に移動
- `Ctrl/Cmd + 3`: PR作成に移動
- `Ctrl/Cmd + 4`: レビューフォームに移動
- `Ctrl/Cmd + 5`: 分析画面に移動
- `Ctrl/Cmd + 6`: 設定画面に移動

### 4. **新機能**: 高度な検索
- PR一覧画面の「高度な検索」ボタン
- 日付範囲、レビュアー、ラベルでの絞り込み
- 複数条件での組み合わせ検索

### 5. **新機能**: 通知システム
- 右上の通知センター
- レビュー待ちPRの自動通知
- カスタマイズ可能な通知間隔

### 6. **新機能**: データ管理
- 設定画面での全データエクスポート・インポート
- JSON形式でのデータ保存
- 設定の永続化

## 🧪 テストシナリオ

### PR作成フロー
1. **PR作成**で新しいPRの情報を入力
2. ファイルをアップロード
3. ラベルとレビュアーを選択
4. フォーム送信でPR作成完了

### PRレビューフロー
1. **PR一覧**でレビュー対象のPRを選択
2. **レビュー**ボタンをクリック
3. **レビューフォーム**で必要な情報を入力
4. フォーム送信でレビュー完了

### フィルタリングテスト
- ステータス別フィルタリング
- 検索機能での絞り込み
- 複数条件での組み合わせ検索

### レスポンシブテスト
- デスクトップ、タブレット、モバイルでの表示確認
- 異なる画面サイズでのレイアウト調整

## 🎨 カスタマイズ

### サンプルデータの変更
`script.js`の`samplePRs`配列を編集して、テスト用のPRデータを変更できます。

### スタイルの調整
`styles.css`を編集して、色やレイアウトをカスタマイズできます。

### 機能の追加
`script.js`に新しい機能を追加して、テストケースを拡張できます。
